# P&D AI Sourcing（プロトタイプ）

デモ動画から整理した「機能要件一覧」のうち、大分類 **共通**（FR-001〜004）と **見積依頼**（FR-005〜019）を試せる Web アプリです。

## 使い方

ビルド不要です。`index.html` をブラウザで開くか、次のコマンドで配信します。

```bash
python3 -m http.server 8000
```

`http://localhost:8000` を開き、「RFP作成」→「新規見積依頼」から進めます。「サンプル文を入れる」で入力例が入ります。

## できること

| 画面 | 対応する要件 |
| --- | --- |
| 左側の統合メニュー（WORK / MANAGE / COMMUNICATION / SEARCH / REPORT） | FR-001〜004 |
| 1. 依頼内容の入力（案件情報＋自然文） | FR-005, 006 |
| 2. 依頼情報の整理（品目・目的・仕様などに構造化、編集可） | FR-007, 008 |
| 3. 要件マトリクス（カテゴリ別・必須/希望、編集して確定） | FR-009, 010 |
| 4. 候補選定（社内データ照合、スコア、適合率、リードタイム、推奨根拠、企業選択、条件確認表） | FR-011〜018 |
| 5. RFP生成（編集、コピー、テキスト保存） | FR-019 |

メニューのうち比較表・決裁・チェック・チャット・検索・レポートは導線のみで、画面は「準備中」です。

## プロトタイプとしての前提

- **AI は擬似実装です。** 依頼文の構造化はキーワードと正規表現、候補評価は取引先マスタとの照合による計算で、LLM は呼び出していません。
- **取引先データは架空です。** `data.js` のマスタを書き換えると候補と評価が変わります。
- 案件はブラウザの localStorage に保存します。サーバー、認証、RFP の送信機能はありません。
- スコアの配点は仮置きです（条件適合率 50／社内評価 20／納期適合 12／取引実績 10／カテゴリ適合 8）。

## ファイル構成

- `index.html` 画面の枠
- `app.js` 画面描画と処理（構造化、マトリクス生成、候補評価、RFP生成）
- `data.js` メニュー定義、カテゴリ別の標準要件、取引先マスタ
- `styles.css` スタイル
