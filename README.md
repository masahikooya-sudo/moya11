# P&D AI Sourcing（プロトタイプ）

デモ動画から整理した「機能要件一覧」（FR-001〜065）を一通り試せる Web アプリです。

## 使い方

ビルド不要です。`index.html` をブラウザで開くか、次のコマンドで配信します。

```bash
python3 -m http.server 8000
```

`http://localhost:8000` を開きます。初回起動時に、進み具合の異なるサンプル案件が3件入ります。

## できること

| メニュー | 内容 | 対応する要件 |
| --- | --- | --- |
| 左側の統合メニュー | WORK / MANAGE / COMMUNICATION / SEARCH / REPORT | FR-001〜004 |
| RFP作成 | 依頼入力 → 依頼情報の整理 → 要件マトリクス → 候補選定 → RFP生成 | FR-005〜019 |
| 比較表生成 | 基準金額・削減額・削減率、見積と条件の横並び比較、充足判定、AIコメントと要約、編集・再生成、企業評価タブ | FR-020〜028 |
| 稟議作成支援 | 稟議情報の入力、決裁区分、関係者の意見と回答状態、取りまとめ、稟議書の作成・プレビュー・出力 | FR-029〜036 |
| プロセスチェック | 件数サマリ、案件別の実施率、判定結果、AI指摘と必要なアクション | FR-037〜042 |
| 法令チェック | 案件ごとの点検リスト（判定ロジックは未定のため記録用） | FR-043 |
| 契約チェック | 条文表示、リスク抽出、理由と改善提案 | FR-044〜047 |
| チャット | 社外サプライヤ／社内、案件・担当者・進行状況の表示、時系列の履歴 | FR-048〜051 |
| Knowledge / Past event / Trend | 質問文での検索、検索対象の切替、AIによる要点整理、参照先カード | FR-052〜058 |
| レポート出力 | KPI、棒・折れ線・レーダーの各グラフ、案件別の状況、手順チェック一覧、印刷／CSV出力 | FR-059〜065 |

## プロトタイプとしての前提

- **AI は擬似実装です。** 構造化・候補評価・比較コメント・契約チェック・検索は、キーワード照合と計算で動いており、LLM は呼び出していません。
- **データは架空です。** 取引先、見積回答、ナレッジ、市況メモ、レポートの過去月の値はダミーです。見積回答は「見積を取り込む」操作で自動生成します。
- **判定基準は仮置きです。** スコアの配点、相見積3社以上、金額別の決裁区分、契約チェックのルールは、社内規程にあわせた調整が必要です。
- 法令チェック・契約チェックの内容は例示で、法的な判断を示すものではありません。
- 稟議は書類の作成までで、承認ワークフローは含みません。チャットの相手からの返信は自動応答です。
- データはブラウザの localStorage に保存します。サーバー、認証、外部への送信機能はありません。

## ファイル構成

- `index.html` 画面の枠
- `app.js` 共通の描画と RFP作成フロー
- `common.js` 各画面の共通処理（見積生成、プロセスチェックの判定、サンプル案件）
- `pages-work.js` 比較表・稟議
- `pages-manage.js` プロセスチェック・法令チェック・契約チェック
- `pages-comm.js` チャット・検索
- `pages-report.js` レポート
- `data.js` / `data2.js` メニュー定義とダミーデータ
- `styles.css` スタイル
